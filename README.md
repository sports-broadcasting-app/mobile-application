# Where to Watch

A mobile application that helps users find which TV channels or streaming platforms are broadcasting their favorite sports events.

## Getting Started

### Prerequisites

- Node.js 18+
- Yarn
- Expo CLI (`npm install --global eas-cli`)
- Expo Go app on your device (for development)

### Installation

```bash
yarn install
```

### Running

```bash
yarn start
```

Scan the QR code with Expo Go (Android) or Camera app (iOS).

### Testing

```bash
yarn test
```

### Linting

```bash
yarn lint
```
